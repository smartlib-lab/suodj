# 悲哀之歌

麦彭仁波切·造论

索达吉堪布·翻译

呜呼胜者天众三根本，汝以智悲关照浊时众，

思维我等所作诸行为，非得不唱忧伤悲愁歌。

难得人身无义而空耗，已舍无定死亡之提防，

不思因果业重形象僧，若有如我悲尊当视之。

珍爱身躯不忍细火星，谁能忍受卧于燃铁地，

不知明日死亡转恶趣，感受彼苦祈求上师知。

无始串习增上作意见，犹如猪前不净合其意，

虽说无执远离诸戏论，难得离心本相实效见。

充腹闭时模糊修行者，顽固执著自以假装相，

若遇违缘此时较余劣，如是无力修行有何用？

三宝作证发誓显密戒，欲换一杯酒或瞬淫乐，

如是自心无有惭愧者，为何尚求跟随胜士位？

一切轮回现相皆变性，尤无可信寿命如闪电，

然而自心稍无忧愁者，未来排场众事感稀有！

诸众父母授持菩萨戒，害自利他彼此相换时，

则即露出虚伪之本相，其为无愧自慢真稀奇！

一切现有清净佛坛城，有相无相道中必见性，

然无少许生起定解者，若彼密士则谁非密士？

善巧等持物咒仪轨要，具有信心精进稳禅支，

修持天咒无二得果位，彼者为何少如昼群星？

精通甚深便脱窍诀要，生起无二智故制分别，

务必自尽贪嗔之波浪，然今岂有如是断惑者？

乐者求福不念死亡法，苦者不思业感行非法，

自心恒时取舍诸苦乐，如同绸文求不得边际。

若得财富愈想得福裕，未得彼者三门勤苦劳，

假装利他所奉诸财物，积累为留临死之所缘。

若赞贡高自慢如燃火，若谤不喜忧伤出粗语，

何行亦成不安分别涛，永无安住轻松之时机。

无始串习二取分别念，难以证悟无贪如幻性，

所行所为虽现极善妙，而未断绝世间之八法。

外相身势举止静温和，如掌漏水风心之分别，

染意所引漂泊无定处，为何如是散漫诸寻思？

心续坚固较前更贪执，妙衣善著五毒此肉身。

为其称上高僧之美名，众多有情以为胜引尊，

朗朗祈祷恭敬而顶礼，发心自己所有诸财物，

诚心立即供养为其前，彼亦假象诱众真悲伤。

外现内外诸法皆变化，内观自心恒旋贪嗔轮，

具知友等由从何思维，如海游船唯生悲伤因。

无免死亡之时无善法，何行无定乱识如狂疯，

自由随意宽松安住者，呜呼我等谁为受诱惑？

内外齐全今来具安乐，其无少许所隐之过患，

自心无垢清净如水晶，如得光明之时应生喜。

二取波浪涌上此片刻，未修上师教诲如我等，

三门所行皆成起忧伤，三根诸佛为我应加持。

铁龙年麦彭者对此现相法稍起悲哀此时所造也。
