# 3．咒生空行母

所谓“咒生空行母”，一般来讲，按照恩札布德亲著的《胜乐略续释》中所说：“咒生使者，是受生于中土等地的空行母。她们中的一些，是依靠修道使相续得以净化而成为空行母的。”关于这类空行母，《胜乐耳传引导文·智慧明灯》中说：“她们通过修行力获得成就，诸如觉姆哲毕嘉姆或玛嘎瓦桑波。”关于刹生空行母与咒生空行母的区别，有些大智者解释说，刹生空行母是依靠刹土大主尊的加持而成为瑜伽母的；咒生空行母是依靠禅定、持诵等而成为瑜伽母的。还有人声称，她们是通过住地空行母与世间使者的特征来辨别的。也有人说是以安住于三远离和安住于生起次第的差别来区分。

在这里，因为解释“咒生”的释词有两种不同的说法，所以咒生空行母存在两种认定方式。有些人认为，她们是通过持诵、修行密咒而成为空行母的；还有些人认为，她们生于父母是持咒成就的瑜伽士的种族中，各说不一。其中的第一种观点，阿阇黎蒋华札巴所造的《誓言释》中说：“咒生空行母是勤奋持诵、修行密咒的女子，她们内心获得了禅定的智慧，身体现为女子相。”绕那绕吉达尊者所著的《难释·莲花》中讲到：“所谓咒生空行母，是依靠灌顶等而次第具足缘分，精勤于禅修与持诵等的女众……”同样，大阿阇黎嗔恨金刚所造的《不明之意而云游者阿桑革德令其明示》中说：“咒生空行母是以女子身份观修生圆次第而获得了四禅智慧。”其根本密意与上述说法一致。

这类空行母从内部可以分为两种，一种是依靠女身修第一层瑜伽——单一的生起次第获得成就，成为空行母；另一种则是依靠女身修生圆双运瑜伽得以成就，成为空行母。这两种都是依密宗道而成为空行母的，所以才有了“咒生”的名词与意义。

第二种观点，是从“转生于父母是持咒瑜伽成就者的种族中”这一角度而安立的。《大手印文集》中说：“咒生空行母是密宗成就者所生之女，对契合相续的密宗道具有渴求的信心，这就是咒生明妃，例如至尊玛尔鄂的儿女中出现的空行母。”琼波瑜伽派的《胜乐五本尊传》中讲到：“咒生空行母是指前世与今生由密宗成就者的父母所生之女，她依靠各类密法净化相续，对此具有希求与信心者。”伏藏大师日称的《空行标记相悉地源》中也有类似论述。

刹生、咒生、俱生这三种空行母，不仅在新旧密宗诸续部中非常有名，我们的怙主法王如意宝也特别强调，他老人家从境界中无勤流露出的《道情歌·持觉空坚地之本相》中提到：“依于咒生空行之缘起，自在驾驭刹生空行众，现见俱生空行真实性。”出自德卓法类的《作明佛母修法·传承祈祷文》中也说：“愿依咒生空行缘，现见刹生空行众，现前俱生空行性……”不仅如此，喇荣莲花空行聚集洲[^1]的三大根本洲之命名，也是由刹生空行、咒生空行、俱生空行的名称排列而成，这样的安排，想必有一定的密意和理由。

事实上，在一个坛城中也具足这三种使者及她们之间相互圆融等道理，是另一种安立方法，正如续中所说的“渐次非渐次”。咒生、刹生、俱生三种空行母，有依靠前前而形成后后的顺式次第，以及与之相反的逆式次第两种不同方式。这些道理细讲起来有很多，但因不合时宜而暂且不表。如欲深究，请参阅诸大续释便可了知。

证智所成义光明，法性空中悲游戏，

胜共悉地赐行者，了义空行应礼境。

乐空双运舞翩翩，骨饰花珞飘飘然，

黑日嘎尊之密友，稀有悦耳乐音名。

金刚贪视青莲箭，射中千勇之心间，

持幻明妃之禁行，刹咒俱生使者赞。

有谓空行视可怖，有谓空行生爱慕，

名同含义各相异，犹如森达巴之名。

未悟空行之实相，增益空行以虚名，

能失空行殊胜性，总集诸佛师所说。

行空未必是空行，称名空行亦不定，

是出世间空行故，善辨空行尤重要。

[^1]: 莲花空行聚集洲：喇荣五明佛学院的尼众学院，即现在的喇荣寺。
