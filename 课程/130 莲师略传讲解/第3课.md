# 第3课

2025年10月3日

昨天讲到，莲花生大士降生时，他的无名指、眼睛、嘴唇和身上，都有一些类似莲花的妙相。所以，父母为他取名为“莲花生”。

家里为这个孩子举办了盛大的庆生宴，

印度一直都有这个传统，听说现在也一样。

邀请了一些婆罗门相师为他看相。

给新生儿看相的传统，古印度一直有。在佛经里面，某家人生了孩子，经常会请婆罗门相师给孩子看相。我问过他们现在的情况，好像说是没有了。

历史上，印度被英国统治了190年，1947年才独立。当时一些法律规定，要废除阶级或阶层的差别制度。所以，现在除了偏远的地方，给初生孩子看相的现象已不太多。

有的相师预言他将来会执掌国政；有的预测他会成为小国王；有些则授记他会住在尸陀林，并失去王族种姓。

莲师后来确实去了各个不同的尸陀林，失去了王族的种姓。这个相师说得比较准。

众说纷纭，莫衷一是，但他们一致认为他将是一个旁人难以胜伏的人。

所有相师都认为，这个孩子将来会成为一个非常了不起的人。

有些人学了一点理论，尤其是学了中观和因明，对看相、打卦等一概不承认。这有点极端。有些人不管做什么都要打卦：“我明天要出去一趟，先打个卦看看！”也有点过于执著。

当问到一位云游至此、修行超凡的瑜伽士时，

这个瑜伽士四处云游，境界超凡。他说得更准。

他说：“这个孩子将成为密宗的卓越修行者，因为他具足了莲花部的所有特征，所以会蒙受阿弥陀佛的加持。”

一些莲师祈祷文中说，莲师是释迦牟尼佛身、观世音菩萨语、阿弥陀佛意三者的总集应化身。

因此，孩子的名字被取为“莲花阿瓦巴色”。

莲师最初的名字叫做阿瓦巴色，意思是莲花光。

孩子渐渐长大，开始学习语言文字、文法学、因明学、医学、工巧学以及八观察等所有微观知识，并轻松掌握、通达无碍。后来，他在康绕卡城一所寺院的一位持戒师面前皈依并受了五戒，

从传记看，莲师并非一出生就是大成就者。最初，他也示现为普通的修行人，经过显宗到密宗的次第修行，最后才成就。

听受了《俱舍论》和经藏的许多教义。他还在密宗阿阇黎现德日巴前接受了事续、行续、瑜伽续许多坛城的灌顶，

他接受灌顶，也是先从外续部开始。我们经常说的“现德瓦”，可能就是这里的“现德日巴”。

所有抉择部的花都落在了莲花部的本尊上。

事续和行续灌顶都有这个传统。唐密的主要经典《大日经》中讲，进入坛城要先供养、顶礼，然后投花，花落在哪里，自己就选择相应的本尊。东密兴盛于日本，在他们的一些仪轨里面，灌顶和入坛城也要投花。我们现在灌无上密法的顶时，也有投花的环节。

此外，他还在一位商主之子、被视为观世音化身的成就者卡得瓦，以及身份为娼妓但实则是真正金刚持的邬金地方女性大成就者色卡达德面前听法，并依止他们得到了许多内密教言。

一位是观音菩萨的化现，一位看起来是妓女、实际上是金刚持。莲师在这两位上师前都听了法。

我那天说了，达仓罗匝瓦的《邬金游记》，你们最好看一下。里面好像没提莲师在这里的情况。我是很久以前看的，记不太清了。当时的邬金是佛教圣地，非常殊胜。不像现在的巴基斯坦，完全被伊斯兰教控制。

在达仓罗匝瓦的游记里面，提到过一个活了一千岁的女人。其实按现在的日历来算，莲师到藏地之前，已经一千多岁了。根据有些佛经和传记的记载，释迦牟尼佛涅槃八年后莲师降生。莲师来到藏地桑耶是公元8世纪。藏地普巴派历算认为，佛陀从出世到现在有两千九百多年。算下来，莲师应该是一千六百岁左右来的藏地。

而莲师广传《班玛瓜唐》中说，莲师是在佛陀出世后三千年才来藏地的。有些成就者解释说，古印度常以半年为一岁，所以他们的三千年其实是一千五百年。总之，莲师获得长寿持明果位后，一直没有示现圆寂，在印度和藏地待了很长时间，最后以大虹身前往罗刹国。

用世间分别念来算莲师的年龄，确实比较困难。世间人一般认为，佛陀是公元前五百多年示现涅槃的。过了八年，莲师出生。到了公元8世纪，莲师才来藏地。中间这么长的时间，莲师一直活着。用世间分别念确实很难解释。而且许多传记和历史都难以考证。

其实，关于早期藏地和印度的很多历史人物，都缺乏详细的文字记载。直到后来，才逐渐有更多记录历史的习惯。

不管怎样，莲师的神变力不可思议，他在一部分众生面前显现为胎生，在另一部分众生面前显现为化生，完全合情合理。就像《西游回记录》里面，上师答记者问时说的那样：“一地菩萨一刹那间能显现一百个化身，列绕朗巴同时转生为两个人是轻而易举的。”[^1]莲师既然获得了长寿持明，寿命已得自在，那他住世多少年也都没问题。其他宗教对圣者也有类似的阐述。

多罗那他造的《密宗大成就者奇传》里面，有个叫格格燃扎的大瑜伽士，也摄受过莲师，给莲师传过法。他白天给一千只狗说法，晚上在尸陀林作禁行。这些事迹虽然难以想象，但却值得我们思考。

[^1]: 《西游回记录》：“从获得一地起，在一个时际刹那，就能示现一百个化身；二地菩萨能示现一千个化身；三地菩萨能示现十万个化身……至于列绕朗巴，他在世时就曾示现过化身，一个化身去了汉地，一个化身在卫藏讲经说法，相关情节在他的传记中有记载。所以，示现两个化身是轻而易举的事。”
