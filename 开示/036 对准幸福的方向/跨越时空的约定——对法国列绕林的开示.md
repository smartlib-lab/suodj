# 跨越时空的约定

——对法国列绕林的开示

2024年11月11日

主持人：

今天我们非常开心，邀请到了索达吉堪布仁波切，与我们线上同步连接列绕林，一起进行交流。

1993年，法王如意宝和索达吉堪布仁波切一起来过这里。近几年，越来越多的喇荣弟子来到了列绕林。我相信以后两位上师的弟子会更加团结和合，真正以佛法利益世上无量无边的众生。

屏幕这边招手的都是法国列绕林的朋友们，他们来自英国、荷兰、意大利、德国、西班牙、瑞士、澳大利亚、比利时、美国、以色列、加拿大、瑞典、俄罗斯等各个国家。在这个殊胜的日子里，我们与来自世界各地的同学和朋友们欢聚在一起，希望聆听堪布的开示，让我们更好地弘扬佛法、利益众生。

OK.今天为了便于翻译，我就用汉语来简单讲讲。

今天是11月11日，在中国被定为双11购物节，这个节日一度很火，算是一个特殊的时间。这次现场参与的人数虽不算很多，但是涉及了全球许多国家，也非常吉祥。所以，这次可以说是各国人士共同弘扬佛法、利益众生的一个会议。

法王晋美彭措和索甲仁波切曾在31年前于法国列绕林会面。两位尊者当时共处的时间不长，只有十天左右，但是结下了意义非凡的缘起。虽然这两位伟大的上师已在众生面前示现圆寂，但他们创建的道场、传讲的佛法、培养的弟子，遍布世界各地，直到今天依然在弘扬佛法、利益众生。当初索甲仁波切说过，很想来五明佛学院拜访，法王如意宝也表示，有机会一定要再来列绕林，两位大德当时虽然如此示现，但后来未能成行，这广大的弘愿要留给我们后人来实现。

法王如意宝1993年的西方弘法之行持续了三个月，在我的记忆中，法王在列绕林这一站是最开心的。两位尊者心心相印、见行如一，他们留下的珍贵教言恰能说明这一点。不论法王如意宝所造的大圆满相关著作，还是索甲仁波切撰写的《西藏生死书》，这些智慧的结晶如今依然流传世间，令无数人从中获益。所以我觉得，虽然两位上师的色身暂时示现融入法界，但是他们留下的加持和证悟，对我们每个传承弟子来说，都是一座无限的宝藏。

值得欣慰的是，两位尊者建立的道场——喇荣沟和列绕林，现在依然以自己的方式存续着。这两个道场也是他们一生中最为重视的，我们每个弟子都应当投入心力去维护。我想，两个道场之间以后也会有更多互相交流往来的机缘，各方面的因缘都会越来越好。我也经常对所有堪布堪姆说，只要有能力，我们应该继承和维护这些前辈大德们留下的宝贵遗产，尤其是像列绕林这样的佛法中心，一定要不遗余力地从各个方面投入行动，去学习他们的传统、支持他们的事业。

我跟索甲仁波切最后一次见面，是在泰国的第七届世界佛教研讨会上。虽然那时候索甲仁波切的身体不是太好，但我们依然彼此约定，要持续交流和合作，尽力地弘扬宁玛巴的大圆满法——我们有过这样的约定。

我知道，创巴仁波切和索甲仁波切的很多西方弟子，对上师的信心如对佛陀一般，极其恭敬、极其欢喜，我认为这一点十分重要。我自己经常这样想，我们的上师，不论是索甲仁波切还是法王如意宝，他们表面上虽然和普通人一样，也要吃饭，也会示现生病和衰老，但实际上他们证悟的境界是极高的，他们利益众生的心更是无与伦比的。从这两个角度来看，我觉得这样的上师非常非常伟大。虽然当别人问起，我们会说自己是某某上师的弟子，但有时心里会感到些许惭愧，因为上师那么伟大，而自己的相续中却没有太多功德。所以，我希望每个人都好好想一想，我们能遇到这样真正有开悟境界和利他心的伟大上师，是何等的荣幸！

如今，全球正发生着此起彼伏的变化，我们每一个拥有着精神信仰和内观财富的人，依靠上师们传下的教言和自己的努力修行，确实显得非常与众不同。现在是一个非常特殊的时代，从世间角度来看，正如埃隆·马斯克所说，任何人通过互联网都可以成为任何领域的专家。这句话对我们佛教徒也同样适用，不论学显宗或密宗的任何法，在这个网络时代都非常方便。既然有这样的机会，大家一定要努力闻思修行。虽然目前在某些方面存在一定的不便，但与此同时，在更多的方面却更加方便。因此，在这个时候，大家千万不能浪费时间，一定要把修心重视起来，将我们所得的大圆满法与自心真正结合。

说到修心，即使短短几句大圆满法要，对我们的相续都是极其有利的，就如当年法王如意宝在法国传讲的大圆满修法。我后来把那些传法内容整理了出来，记录在《西游回忆录》一书中。法王当时在列绕林所做的开示非常殊胜，而且全然是智慧的流露，不是提前查阅资料、专门备课的结果。这些来自大德智慧自然流现的法要，是一种极其珍贵的财富。

我最近正在讲解记录当年法王西方弘法之旅的《西游回忆录》，现在已经讲到了第八站——加拿大，接下来很快就要讲到第九站——法国。法王在这一站传的法极为甚深，考虑到听众中很多人没得过灌顶，这些内容是否要公开讲解，我还在犹豫。

回想这段三十多年前的往事，那时我只有三十二岁，刚才在屏幕上看到一些熟悉的面孔，当年你们也都十分年轻。随着岁月的流逝，我们现在都上了些年纪，但心中的信仰始终没有变过。记得当初在法国的时候，有一次大家在山上一起念经、供护法，当时现场有几个小孩在人群中跑来跑去，而一晃眼他们都已经变成四十多岁的中年人了。器世界和有情世界都是无常的，谁也无法改变这一点，但我经常感到欣慰和欢喜，因为我们拥有一种内在的财富，这种财富是谁也抢不去、夺不走的，永远保存在我们每个人自己的心中。

时间不多了，我就不多说了。希望在座各位，经常祈祷自己的传承上师和莲花生大士，这是非常重要的。我们在修行过程中，不论遇到任何痛苦和不幸，都要把它当作一种修心的助缘，将之转为道用，这一点是很关键的。同时，要好好护持自己的道场，没必要跑去外面四处游荡。我最近正在翻译萨绕哈巴尊者的《道情歌集》，里面有一个比喻很有意思：凡夫因为被烦恼束缚，整天东奔西跑；而圣者因为已经开悟，反而会安住在一个地方。就像骆驼背上如果驮着很重的东西，它就会跑来跑去；但如果什么东西也没驮，它反而就不乱动了。这是一个很颠倒的现象，但也是很现实的问题。这个比喻大家可以多多思考。

我最近一直在翻译莲花生大士的教言和萨绕哈巴尊者的道歌，还有一些其他藏地大德的著作，我在这些事情上付出了很大的努力，但是在修行上投入的时间比较少，说来有点惭愧。但不管怎样，今天在网上见到这么多的法友，我感到特别高兴。

最后，希望大家事事都能开心。其实，世间的一切都是心的幻化，如果我们觉悟到了这一点，在这世上就没有面对不了的事。

谢谢大家！OK.（笑）
